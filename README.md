# Iron Man — Level 1

A simple browser game prototype built around a scrolling background and an Iron Man sprite. The player can move horizontally and jump while gravity pulls the character down.

## Controls

- **Up arrow:** jump
- **Left / Right arrows:** move horizontally

## Stack

- HTML5
- JavaScript with p5.js and p5.play
- CSS and local artwork under `images/`, with support libraries under `lib/`

## Run

Open `index.html` in a browser. Keep `images/`, `lib/`, and `CSS/` in their current locations for the assets and libraries to load.
